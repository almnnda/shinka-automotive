# PT Shinka Sembada Automotive

Company profile website for PT Shinka Sembada Automotive, an automotive engineering consultancy based in Kelapa Gading, Jakarta. Motto: Quality in Motion.

Live site: https://almnnda.github.io/shinka-automotive/

The site is a single self-contained `index.html` (all assets inlined). Facts sourced from Dokumen Perencanaan Tata Letak Pabrik Produk Kursi Tengah Mobil Ertiga (Modul 1) and the official company logo.
